## The entry

One word, exactly as the judge reads it:

```
Weathervane
```

A weathervane does not change its mind; it changes its face, instantly, and
then stands there as if it always pointed that way. A boss like that agrees
with the last person who spoke, is certain in the meeting, is certain again by
the corridor in the opposite direction, and is sincerely puzzled that anyone
remembers the earlier version.

That is why the word holds up alone. For half a second it sounds like a garden
ornament, and then the habit snaps into place, which is where the laugh is: the
surprise is the double-take, not a rare vocabulary. It names one recognisable
habit rather than a general vibe, so it needs no caption, and it travels -- a
kitchen, a warehouse and an office all have someone whose conviction follows
whoever is in the room, and no industry has to be explained for the word to
land.

## Run it

Python 3.13, standard library only, no network, no randomness, no arguments.

```sh
python3 main.py
```

The program creates `/output` if it is missing and writes the word to
`/output/entry.txt` as UTF-8 with no trailing newline. Rerun it as often as you
like: the bytes are identical every time.

```sh
python3 -c "print(repr(open('/output/entry.txt','rb').read()))"
# b'Weathervane'
```
